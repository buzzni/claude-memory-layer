## 검증과 범위

각 결함은 수정 전 회귀 테스트 실패를 확인한 뒤 수정했다. 1차 전체 실행에서 CLI 테스트 4건이 15초 제한을 초과했으며 해당 두 파일은 worker 1개로 재실행해 모두 통과했다.

최종 검증:

- `npx vitest run --maxWorkers=1`: 241개 파일, 1,646개 통과 / 1개 실패(총 1,647개). 실패는 감사 fixture가 60,000ms를 기대했으나 두 번 시각 읽기 사이 1ms가 지나 59,999ms가 된 경우다.
- 해당 fixture 수정 후 `tests/apps/memory-audit-report.test.ts`: 7개 모두 통과. 수정 후 전체 suite를 다시 실행하지 않았으므로 단일 전체 실행 green으로 보고하지 않는다.
- typecheck, build, architecture, public-output-privacy 통과. 공개 출력 검사 발견 0개.
- lint 오류 0개, 기존 경고 45개. diff 공백 검사 통과.

사용자 저장소의 과거 평가나 부분 backfill 기록을 일괄 재작성하지 않았다. 성능·토큰 절감 목표는 이번 정확성 검증으로 입증하지 않는다. 출처 전체 검사와 많은 참조 후보의 페이지 조회는 데이터 규모에 따라 처리 시간이 늘어날 수 있다.
